# 阿沐：用户全身骑行视频素材

来源为用户在本会话提供并要求处理的 `生成指定动作的循环视频 (3).mp4`。用户指定角色名称为“阿沐”，模型 ID 为 `amu-01`。原视频 SHA-256：`e0cf7cbd7827cb6b6cb85f1c66281689c5bd3a68476a98f44d592eb0bb5b15f4`；720×1280、145 帧、24 FPS。原始视频不随源码或安装包复制；此前近景视频 (2) 未用于本资源。

本次仅处理源视频已有的人物、完整自行车与骑行动作：去除青绿色背景和地面投影，使用局部背景及前景颜色估计保留软透明边缘、蓝白衣料、灰色车架、细辐条和辐条间透明孔。没有 AI 重画、补帧、逐帧重新定位或复用旧角色素材，也不包含原视频音轨。

- `loop.png`：768×768 RGBA APNG，连续选取原视频第 **51–130 帧（从 1 开始，包含首尾）**，共 80 帧、精确 24 FPS、约 3.333333 秒、无限循环。它覆盖约两圈踩踏，端点保持睁眼；每帧使用完整画布的 SOURCE 合成。
- `still.png`：仍取原视频第 **1 帧**，供暂停、隐藏或系统减少动效使用。静态形象不随默认循环的截取起点改变。
- `provenance.json`：完整源视频摘要、选帧区间、共同画布规则、工具版本与产物摘要。

人物和自行车的画布定位由 **全部 145 帧** 的共同包围盒 `[55, 158, 694, 1230]` 决定，固定缩放、底线 734；没有为短循环单独缩放或逐帧居中。原完整 145 帧、约 6.041667 秒动作保留为本地独立产物 `dist/companion-assets/amu-01/full-cycle.png`，同目录另有默认循环、静态图及来源记录；完整版本没有作为额外虚构动作注册进 App。

短循环首尾预乘 RGBA 平均绝对差约 0.01458，片内相邻帧中位差约 0.01635。选择降低了源完整视频在片尾闭眼后跳回开头的变化，但不宣称完全无缝。默认循环与完整动作均经 Pillow 和 FFmpeg 逐帧解码，全部像素与对应处理 PNG 相同，画布边界全部透明。

可复现命令（输入路径由调用者提供，输出必须为新目录或空目录）：

```powershell
python scripts/prepare-companion-video.py --input <source-video> --output <new-output-directory> --matte-profile teal --start-frame 51 --end-frame 130
```

另需 FFmpeg/FFprobe，可用 `--ffmpeg` / `--ffprobe` 指定可执行文件。离线素材工具依赖见 `packaging/requirements-companion-assets.txt`。`purple` 默认分支继续用于阿宝，`teal` 针对这类青色背景，均不是通用人物分割工具。成对帧区间仅选择连续原帧；全部源帧仍参与画布计算，静态图固定使用源帧 1，截取时额外输出完整 `full-cycle.png`。
